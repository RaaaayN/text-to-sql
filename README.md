# Texte vers SQL

Assistant qui traduit une question en une requête SQL unique, l'exécute en lecture seule
et mesure l'exactitude, le coût et la latence. Le projet cible SQLite et le benchmark BIRD.

L'implémentation est en cours. Le parcours exécutable et les résultats reproductibles sont
documentés ici à mesure qu'ils deviennent disponibles.
